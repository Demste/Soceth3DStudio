# Changelog

## 0.2.2

- Made UV-textured models the standard Image-to-3D choices. TripoSG is available per job in Advanced Mode.
- Added TripoSR UV unwrapping and baked albedo using an isolated Windows OpenGL process.
- Added embedded texture and material checks for generated GLBs, Blender previews, and Unity exports.
- Added per-job source texture resolution, optional automatic mesh optimization, and Art Bible vertex budgets.
- Added Windows setup status and access requirements for Stable Fast 3D and SPAR3D in Model Manager.

## 0.2.1

- Added separately selectable TRELLIS.2 INT8 and BF16, TripoSR vertex-color GLB and TripoSG geometry GLB.
- Added isolated local PyTorch adapters, pinned artifact verification, model license and readiness information, and safe shared-file removal.

## 0.2.0

- Added hardware capability analysis, a real CUDA smoke test, and model recommendations with evidence labels.
- Added model families, side-by-side variants, existing file references, local GGUF registration, and project model defaults.
- Added Windows setup choices, Basic and Advanced views, safe Git updates and versioned ZIP upgrades.
- Updated application dependencies to address release-audit advisories.
- Included Art Bible enforcement, structure-aware cleanup, independent LOD revisions and Unity 6 export.
