### Monetized video games

- **Commercial Game Use — Conditional** applies to native Pixal3D INT8/BF16 and TRELLIS.2 INT8/BF16. The reviewed chain permits use of generated assets in monetized games and their marketing, subject to the DINOv3 license and rights to the input images. DINOv3 grants worldwide use of its materials with trade-control and specified end-use restrictions. It has no revenue threshold or separate restriction on selling games containing generated assets. Research publications require acknowledgement. Redistributing DINOv3 files or derivatives requires its license, which is separate from shipping a game asset. Both TRELLIS.2 precisions are opt-in. [DINOv3 license](https://github.com/facebookresearch/dinov3/blob/main/LICENSE.md) · [Pixal3D weights](https://huggingface.co/TencentARC/Pixal3D) · [TRELLIS.2 weights](https://huggingface.co/Comfy-Org/TRELLIS.2)
- **Commercial Game Use — Reviewed** applies to the pinned TripoSR and TripoSG paths in Studio. The upstream code and models are MIT. TripoSG includes an Apache-2.0 DINOv2 encoder and outputs untextured geometry. Both adapters use input alpha supplied by the artist. TripoSR uses the official checkpoint, DINOv1 architecture configuration and BSD-licensed scikit-image surface extraction. Its albedo atlas uses MIT xatlas, ModernGL and glcontext with BSD-3-Clause NumPy in a separate process. [TripoSR](https://github.com/VAST-AI-Research/TripoSR) · [TripoSR checkpoint](https://huggingface.co/stabilityai/TripoSR) · [TripoSG](https://github.com/VAST-AI-Research/TripoSG) · [TripoSG weights](https://huggingface.co/VAST-AI/TripoSG) · [DINOv2](https://github.com/facebookresearch/dinov2/blob/main/LICENSE) · [scikit-image](https://github.com/scikit-image/scikit-image/blob/main/LICENSE.txt) · [xatlas](https://pypi.org/project/xatlas/0.0.11/) · [ModernGL](https://pypi.org/project/moderngl/5.13.0/) · [glcontext](https://pypi.org/project/glcontext/3.0.0/) · [NumPy](https://numpy.org/doc/stable/license.html)

[Community License](https://stability.ai/community-license-agreement) · [Stable Fast 3D terms](https://huggingface.co/stabilityai/stable-fast-3d) · [SPAR3D terms](https://huggingface.co/stabilityai/stable-point-aware-3d)
- For those gated models, register with Stability or obtain the required Enterprise license. Sign in to Hugging Face and accept access separately on each model page. Create a fine-grained token with read access to the authorized repository and enter it at the interactive `hf auth login` prompt in the isolated runtime. Keep the Hugging Face token cache outside the checkout and decline the optional Git credential storage. [Hugging Face gated models](https://huggingface.co/docs/hub/models-gated) · [Hugging Face authentication](https://huggingface.co/docs/huggingface_hub/guides/cli#hf-auth-login)
- Stable Fast 3D and SPAR3D are blocked in the current Windows Studio configuration. Use an isolated Python environment from an x64 Visual Studio 2022 Developer shell with C++ Build Tools, the Windows SDK and a CUDA Toolkit matched to the installed PyTorch build. Validate both native extensions, `texture_baker` and `uv_unwrapper`, before testing the gated model. Remeshing has its own native dependency. SPAR3D also loads AlphaCLIP separately. The upstream ComfyUI extensions require the same native build in ComfyUI. Studio displays setup status, and weights are excluded from its releases. [Stable Fast 3D installation](https://github.com/Stability-AI/stable-fast-3d#installation) · [SPAR3D installation](https://github.com/Stability-AI/stable-point-aware-3d#installation)
