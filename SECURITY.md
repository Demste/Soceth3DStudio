# Security

Report security issues through [GitHub private vulnerability reporting](https://github.com/Demste/Soceth3DStudio/security/advisories/new) when available. If it is unavailable, open a minimal issue asking for a private contact without disclosing reproduction details or project data.

Include the Studio version, affected component, expected impact and a minimal sanitized example. Omit your local token, database, model files and any private workspace paths.

Studio, ComfyUI and Ollama are designed to listen on loopback. Use trusted local provider installations and keep the Studio token private. The Windows ZIP includes a SHA-256 sidecar. Keep application, GPU driver, Blender and provider software updated separately.
